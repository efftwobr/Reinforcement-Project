This code is intended for use in Visual Studio code
To use, make sure to have the following essential files open in VSC:
 - __init__.py
 - SAC.py
 - state.py
 - wordle_words.txt
 - wordle.py

Important notes:
- Make sure you uncomment only the environment name you wish to use
- To change the number of episodes it trains on, change the 'episodes' variable just below
- For file saving and loading, uncomment/comment the respective sections in the code between the #s
